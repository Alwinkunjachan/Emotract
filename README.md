# Emotract

A full-stack real-time chat application built with the MERN stack, featuring encrypted messaging, real-time online/offline status tracking, an admin dashboard with analytics, and email-based content moderation.

## Tech Stack

**Frontend:** React, TypeScript, Tailwind CSS, Socket.IO Client, ShadCN UI, Recharts

**Backend:** Node.js, Express.js, MongoDB, Redis, Socket.IO, JWT, Nodemailer

**Infrastructure:** Docker, Docker Compose

## Getting Started

```bash
git clone https://github.com/Alwinkunjachan/Emotract.git
cd Emotract
docker-compose up --build
```

Refer to the [Setup Guide](docs/SETUP.md) for detailed configuration and environment setup.
